# Метрики геометрии для сравнения base, CE и CE+SupCon

Все значения ниже получены на одних и тех же 1 699 текстах WildGuardTest. Векторы — masked mean последнего слоя E5, затем L2-нормировка. PCA для каждой модели обучена отдельно на центрированных векторах. Метрики являются описанием этой выборки.

## Основной набор

| Метрика | Зачем | Base | CE | CE+SupCon |
|---|---|---:|---:|---:|
| `pc1_share` | Доля дисперсии первой главной компоненты; показывает концентрацию вариации по одной оси | 0.071 | 0.645 | 0.818 |
| `participation_ratio` | Эффективное число направлений дисперсии | 80.62 | 2.38 | 1.50 |
| `variance_trace` | Общий разброс; нужен вместе с PR, особенно внутри классов | 0.201 | 0.746 | 0.143 |
| `cosine_gap_macro` | Разность среднего внутриклассового косинуса и косинуса между классами | 0.003 | 0.554 | 0.136 |
| `knn_macro@10` | Локальная группировка по safety-метке; случайный уровень здесь 0.500 | 0.693 | 0.844 | 0.843 |

`variance_trace` и `participation_ratio` нужно дополнительно показывать отдельно для safe и harmful: [полная таблица](../guardrails_geometry_results/run_20261018T134157_442709Z/three_way_geometry_by_class.csv). Для CE+SupCon trace внутри safe/harmful равен 0.048/0.110 против 0.375/0.595 у CE. Почти одинаковая kNN-purity при этом скрывает заметно разную форму облаков.

## Где находится код

- [Ноутбук](../guardrails_geometry_colab.ipynb), ячейка `embeddings`: `encode()` делает masked mean, `normalize()` делает L2-нормировку.
- Ячейка `metrics`: `spectrum()` считает PC1 share, PR и trace через собственные значения ковариации; `class_cosines()` считает cosine gap; `neighbors()` и `evaluate()` считают kNN-purity. Там же есть `uniformity_t2` и TwoNN как дополнительные диагностики.
- Ячейка `comparison`: `summary()` собирает метрики для base и CE+SupCon.
- Ячейка `ce-control`: применяет те же функции к CE и сохраняет [сводную таблицу](../guardrails_geometry_results/run_20261018T134157_442709Z/three_way_comparison.csv).
- [Скрипт PC1](prepare.py) отдельно проверяет связь координаты первой компоненты с длиной запроса и safety-меткой; [график](../guardrails_geometry_results/run_20261018T134157_442709Z/pc1_semantics_followup/pc1_label_and_length.png).
- [Проверка формул](../.verification/check_guardrails_geometry.py) сверяет косинусы, спектр, kNN и другие вычисления с независимыми эталонными расчётами на небольших данных.

## Что включить в вывод

Эти пять метрик вместе показывают направление вариации, эффективную размерность, размер облака и safety-структуру. Высокая `pc1_share` или низкий PR сами по себе не доказывают потери смысла. Для последнего приготовлен отдельный слепой набор пар с человеческой оценкой: [протокол](../guardrails_geometry_results/run_20261018T134157_442709Z/pc1_semantics_followup/PROTOCOL.md).
